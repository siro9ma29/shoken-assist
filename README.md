# 所見文アシスト

通知表の所見文の下書きを、観点のチェックから組み立てる教員向けツールです。
単一HTMLファイルで、ブラウザだけで動きます（インターネット接続・外部サービス不要）。

## 3つの版
| 版 | 開き方 | 対象 |
|---|---|---|
| 標準版 | `index.html`（公開URLの先頭ページ） | 学級担任の通知表所見 |
| 外国語活動版（FL） | `fl/index.html`（公開URLの `/fl/`） | 3・4年 外国語活動の所見 |
| 特別支援学級版（SN） | `sn/index.html`（公開URLの `/sn/`） | 特別支援学級（知的障害）の教科等の欄ごとの所見 |

どの版も単一HTMLファイルで、ダウンロードしてダブルクリックでも動きます。

## 使い方（標準版）
- `index.html` をブラウザで開く（ダブルクリックでも可）。v1.33 から、1画面ずつ進む形になりました。
- 最初の画面で「成績一覧から作る」か「一人ずつ作る」を選びます。
  - **成績一覧から作る**：読み込み → 読み取りの確認 → 文字数 → 一人ずつ確認 → 仕上げ（所見一覧）。C4thの「成績Excel出力」（追加する項目「通年　必修観点」「通年　行動の記録」、出力方法「学年毎にシートを分ける」）で出した一覧（.xls または CSV）を読み込むと、A・○は「できる」、△は「課題」（1人1件まで）として項目を選び、おすすめの★（学習面3件・生活面2件）を付けます。そのあと1人ずつ文章を出すので、「OK・次の児童へ」で順に確認します。
  - **一人ずつ作る**：名前と学年 → 文字数 → 項目を選ぶ（学習面・生活・行動面・健康・体力面・特別活動・係活動・人とのかかわり・各教科・特別活動・学校行事の7ページ）→ 文章の確認。
- 「所見一覧」で、全員の文章・字数・状態（未作成／下書き／確認済み）を見られます。全員分コピー（タブ区切り）、1人分コピー、CSV保存、＋児童を追加（成績一覧から作った学級にも手で足せます）ができます。
- 文を足す・外す、文のまとめ方（1観点＝1文／2観点をまとめる）、文字数の自由入力、学年帯は、文章の確認画面の「くわしい設定」にあります。
- キーボード：Enter で主なボタン、← → で前後の児童（一人ずつ確認）・前後のページ（項目）。「元に戻す」で直前の1回分の変更を取り消せます。
- 生成されるのは定型文を組み合わせた下書きです。必ず担任が加筆・確認してから通知表に転記してください。

## データの扱い
- 入力内容（児童名・選択・下書き）は、使っているパソコンのブラウザ内（localStorage）にだけ保存されます。サーバーには送信されません。
- 共有のパソコンでは、作業後に「所見一覧」→「くわしい設定」の「学級をすべて消す」を押してください。
- 特別支援学級版も同じく、入力内容はブラウザ内だけに保存されます。共有のパソコンでは「この児童の入力を全部消す」を押してください。
- このリポジトリには児童の情報は含まれていません。
- 特別支援学級版の「支援の手立て」は、学校の個別の指導計画の観点にそって所見向けの言い回しに書き直したものです。指導計画の原文は含めていません。

## バージョン
画面上部のバージョン表示にマウスを乗せると、更新履歴が表示されます（`index.html` 内の `APP_HISTORY`）。
