# 所見文アシスト

通知表の所見文の下書きを、観点のチェックから組み立てる教員向けツールです。
単一HTMLファイルで、ブラウザだけで動きます（インターネット接続・外部サービス不要）。

## 3つの版
| 版 | 開き方 | 対象 |
|---|---|---|
| 標準版 | `index.html`（公開URLの先頭ページ） | 学級担任の通知表所見 |
| 外国語活動版（FL） | `fl/index.html`（公開URLの `/fl/`） | 3・4年 外国語活動の所見 |
| 特別支援学級版（SN） | `sn/index.html`（公開URLの `/sn/`） | 特別支援学級（知的障害）の教科等の欄ごとの所見 |

どの版も単一HTMLファイルで、ダウンロードしてダブルクリックでも動きます。

## 使い方（標準版）
- `index.html` をブラウザで開く（ダブルクリックでも可）。v1.33 から、1画面ずつ進む形になりました。
- 最初の画面で「成績一覧から作る」か「一人ずつ作る」を選びます。
  - **成績一覧から作る**：読み込み → 読み取りの確認 → 文字数 → 一人ずつ確認 → 仕上げ（所見一覧）。C4thの「成績Excel出力」（追加する項目「通年　必修観点」「通年　行動の記録」、出力方法「学年毎にシートを分ける」）で出した一覧（.xls または CSV）を読み込むと、A・○は「できる」、△は「課題」（1人1件まで）として項目を選び、おすすめの★（学習面2件・生活面2件。学習面の2件は同じ教科で1文にまとめられる組み合わせ）を付けます。そのあと1人ずつ文章を出すので、「OK・次の児童へ」で順に確認します。学習の記録の9割以上がAの児童、または主要教科（3年以上：国語・算数・理科・社会、1・2年：国語・算数・生活）の同じ観点の4分の3以上（4教科中3教科以上）がAの児童には、学習面の最初に学習全体をまとめた文（学習面の総括）が入ります（v1.51、v1.52で判定を変更）。
  - **一人ずつ作る**：名前と学年 → 文字数 → 項目を選ぶ（学習面・生活・行動面・健康・体力面・特別活動・係活動・人とのかかわり・各教科・特別活動・学校行事の7ページ）→ 文章の確認。
- 「所見一覧」で、全員の文章・字数・状態（未作成／下書き／確認済み）を見られます。全員分コピー（タブ区切り）、1人分コピー、CSV保存、＋児童を追加（成績一覧から作った学級にも手で足せます）ができます。
- 「C4th用Excelに書き込む」：C4thから出した所見の取り込み用Excel（.xlsx。列：生徒管理コード・学年・組・番号・氏名・入力年度・入力学期・所見）を選ぶと、番号で照合して「所見」の列に文章を入れた新しいファイル（元の名前_所見入り_日時.xlsx）を保存します。ボタンを押すと手順を大きく表示し、1つずつ確かめながら進めます。手順：① C4thの「通知表入力」→「エクセル出力」で通知表入力用のExcelシートを出力 ② 「C4th用Excelに書き込む」で①のExcelを選ぶ ③ 保存されたファイルをC4thで読み取らせる。
- 文を足す・外す、文のまとめ方（1観点＝1文／2観点をまとめる）、文字数の自由入力、学年帯は、文章の確認画面の「くわしい設定」にあります。
- キーボード：Enter で主なボタン、← → で前後の児童（一人ずつ確認）・前後のページ（項目）。「元に戻す」で直前の1回分の変更を取り消せます。
- 生活面（生活・行動面・健康・体力面・特別活動・係活動・人とのかかわり）の文は、学年帯で言い回しが変わります。低学年（1・2年）・中学年（3・4年）・高学年（5・6年）それぞれに、発達段階に合わせた専用の文があります（低・高学年は v1.54、中学年は v1.55。`index.html` の `BAND_ALT`）。
- 学習面（g1〜g9）の文も、v1.56 から低・中・高学年で書き分けています（各3通り）。低学年は手を挙げて答える・マスに合わせて書く・音読カードなど身近な場面、中学年は理由を挙げる・予想・段落・自主学習ノート・辞典など、高学年は根拠・時間配分・振り返り・司会や記録・複数の資料と出典など。v1.61 から、課題の文（学年共通の観点の34項目）と、「2観点をまとめる」設定でまとめた文（学年共通の43組）も低・中・高学年で書き分けています（`index.html` の `BAND_ISSUE`・`BAND_JOIN`。その学年帯の文がなければ DB の issue・`JOIN_TEXT` を使います）。文を足すときは、学年帯の間や旧文と同じ文を作らないこと、まとめた文の can は辞書形・grow は「〜てきました／〜になりました」、課題は「〜ことがあります」＋手立ての過去形「〜てきました」にすること。特別活動・係活動のまとめた文には `JOIN_HEAD` の場面が文頭に付くので、場面と同じ語を入れないこと。
- **取り上げる学習内容**（v1.49・v1.62）：教科の「できる」の文は、学年が分かるとき学年・学習内容別の文（`index.html` の `GRADE_TEXT`）を使います。各学年の先頭3つが「主な学習内容」で、出席番号で自動に選ぶのはこの中からだけです。算数・理科・社会は、その後ろに教科書（算数・理科：東京書籍、社会：教育出版。令和6年度版）のそのほかの単元を教科書の順に並べてあり、項目の画面の「取り上げる学習内容」で先生が選べます。先生が選んだ単元は番号で保存するので、単元を足すときは必ず各学年の**最後に**足すこと（途中に入れると前に選んだ単元がずれます）。文は c・s・t（各観点の「できる」、辞書形）、tri（「〜てきたことで、〜ようになってきました」）、sp・tp（まとめた文の後ろ側に置く形）の7つです。教科書が変わったら、この後ろの単元を作り直してください。
- 課題の文は、学年末の評価に合わせて「〜ことがあります。〜ようにしてきました。」の形です（v1.54。「今後は〜」は使いません）。
- 文章に「委員会」が入ると、文章の確認画面と所見一覧に「要確認」が出ます。委員会に入っていない児童もいるので、確かめてから使ってください（v1.54。確かめる語は `CHECK_WORDS` に足せます）。
- **文例を見る**（v1.57）：はじめの画面の「文例を見る」、または項目の画面の各カテゴリの「このカテゴリの文例を見る」で開きます。学年帯（低・中・高）とカテゴリを選ぶと、項目ごとに「できる」「伸長中」「課題」の文例を、通知表に載る形（文末を付けた形）で、言い回しの候補すべてを並べます。教科の「できる」は、学年が分かるとき（成績一覧から作るときなど）に使う学年・学習内容別の文も並べます。見るだけの画面で、文ごとに「コピー」できます（児童の選択は変わりません）。実際の所見では、教科名などの書き出しや文末の言い方が児童ごとに変わり、2つの観点を1文にまとめることもあります。処理は `index.html` の「文例を見る（v1.57）」の囲み（openExamples／renderExamples）です。
- **文章を手で直す**（v1.59）：文章の確認画面の「文章を手で直す」で、下書きを直接書き換えられます。「この文章にする」でその児童の文章になり、所見一覧に「✎手直し」の印が付きます（改行は消えます）。手で直した文章は、項目・★・字数などを変えても作り直しません。直したあとに項目などを変えて文章の画面を開いたときと、「別の言い方にする」を押したときは、手直しを消して作り直すか聞きます。作り直すときは「手直しを消して作り直す」を押します（すぐあとなら「元に戻す」で戻せます）。処理は `index.html` の「文章の手直し（v1.59）」の囲み（handEditStart／handEditEnd／handDrop）です。
- **見た目**（v1.60）：機能は変えずに、色（薄いブルーとグレーの地・操作は青・完了は緑・注意はだいだい）、文字とボタンの大きさ、ステップの表示（丸い番号と線、終わった手順は✓）を見直しました。画面の下の「戻る」「次へ」は帯になり、スクロールしても見えます。コピーするとボタンが緑になり、画面の上に「コピーしました」と出ます。作業ファイルに保存すると「保存しました」と出て、上の帯に保存の状態（✓保存済み／●保存中…／●未保存の変更）が出ます。「？ 使い方」で使い方の案内を開けます。「？」に指を乗せると説明が出ます。色を変えるときは `index.html` の「v1.60：見た目の改善」の囲みの `:root` を直します。表示の補助は最後の「見た目の補助（v1.60）」の囲みです（既存の関数は呼ぶだけ）。
- ★は1人5件までです。5件付いているときに別の項目の★を押すと、「設定では★は5つまでです。追加したい場合は他の項目の★を外してください。」と知らせます（v1.58。上限は `MAX_PRI`）。
- 生成されるのは定型文を組み合わせた下書きです。必ず担任が加筆・確認してから通知表に転記してください。

## 使い方（外国語活動版・特別支援学級版）
- **見た目**（SN v1.23・FL v1.5）：標準版 v1.60 と同じ見た目にしました（機能は変えていません）。色・文字とボタンの大きさ・ステップの表示・青い案内の囲み・下の「戻る」「次へ」の帯（狭い画面では固定しない）・コピーしたときの緑のボタンと「コピーしました」の知らせ・「？ 使い方」・「？」の説明。特別支援学級版は、上の帯に保存の状態が出て、作業ファイルに保存すると「保存しました」と出ます（外国語活動版は作業ファイルの保存がないので出ません）。CSSと表示の補助は標準版と同じ内容で、各ファイルの「v1.60：見た目の改善」と「見た目の補助（v1.60）」の囲みにあります。直すときは3つの版をそろえてください。
- v1.4 から、通常版と同じ「1画面ずつ進む」画面になりました。学級全員分を持てます（自動保存・続きから・作業ファイル・CSV）。
- 外国語活動版：最初の画面で「名簿から作る」か「一人ずつ作る」を選びます。名簿から作るは、C4thから出した学級名簿（出席番号と氏名が入った .xlsx／.xls／CSV）を読み込み、出席番号の順に作ります。名簿→確認→文字数→（児童ごとに）3観点の項目→文章→所見一覧。
- 特別支援学級版：最初の画面で「個別の指導計画から作る」か「一人ずつ作る」を選びます（SN v1.5 から。「名簿から作る」を置き換え）。
  - **個別の指導計画から作る**：個別の指導計画（様式3-1 .xlsx）を学級全員分（あれば学級名簿も一緒に）読み込む → 前期／後期を選ぶ → 読み取りの確認（児童との対応・教科の行をどの欄に入れるか）→ 取り込み → 児童ごとに、評価の文から作った下書きを確かめる（「要確認」の印の付いた文だけ見ればよい）→ 所見一覧。
  - **一人ずつ作る**：使う欄（学級で共通）→（児童ごとに）支援の手立て→欄ごとに 項目→文章→その児童のまとめ→所見一覧。計画のない児童、評価が空の欄、「学校から」「行動のようす」もこの項目の画面で作ります。
- 特別支援学級版の「個別の指導計画から作る」（SN v1.5〜）：様式3-1の .xlsx を学級全員分読み込み→読み取りの確認（教科の行をどの欄に入れるか）→取り込み。読み取りのルールは `sn/index.html` の「個別の指導計画（様式3-1 .xlsx）の読み取り」の囲みにあります。
- SN v1.6 から、取り込むと評価の文から欄ごとの下書きを作ります。評価の文を1文ずつ「できたこと／様子／課題／教師の手立て・今後の方針／メモ」に見分け、できたこと・様子の文だけを通知表の言い方（敬体）に直して並べます。「〜が、〜」の文は肯定の側を使います。健康・家庭に関わる文は既定で外し、学級名・人名などは要確認として知らせます。評価の文に支援の語がないときだけ、計画の手立ての言い回しを足します。めやすの字数を超えるときは、優先度の低い文から外します。評価の文がある欄は項目の画面を飛ばして文章の画面を開きます（SN v1.12 からは、項目を選ぶと評価の文から作った文章のあとに足します）。処理は `sn/index.html` の「評価の文の分類・言い換えと、欄ごとの組み立て」の囲みにあり、`node sn/test/kk_bun_test.js` でテストできます。
- SN v1.7 から、文章の画面の下に「評価の文から選ぶ」の一覧が出ます。評価の文を計画の順に、所見での形と元の文を上下に並べ、チェックで使う文を選ぶとその場で文章を作り直します（選んだ結果は `rec.kk.pick`）。健康・家庭／固有の名前／様子を述べただけ／書き癖が残る文には「要確認」の印が付き、チェックを変えるか「このままでよい」を押すと確認済みになります。はじめは要確認の文だけを表示します。欄の「OK」を押すと、残った要確認の文はいまの選び方で確定します。児童のまとめには欄ごとの「要確認 n」、所見一覧には「！」の印と「要確認が残っている児童」の絞り込みが出ます。画面の処理は `sn/index.html` の「評価の文を1文ずつ選ぶ」の囲み（kkRenderPick）です。
- SN v1.8 から、文章の画面の「文章を手で直す」で下書きを直接直せます。「この文章にする」で確定すると「✎ 手で直した文章です」の印が付き（`rec.secs[欄].hand`）、項目・文のチェック・呼び方・字数を変えても作り直しません。チェックの変更・「別の言い方にする」・「この欄のチェックを読み込んだときに戻す」（v1.17 までの「この欄をおすすめの選び方に戻す」）では「手直しを消して作り直しますか」と聞きます（キャンセルなら文章はそのまま。チェックの変更は保存され、同じ欄では続けて聞きません）。「手直しを消して作り直す」で、いまの選び方から作り直します。字数の知らせは、評価の文から作る欄では「下の一覧で使う文を足す／減らす」、手で直した欄では足す・減らすを言いません。処理は `sn/index.html` の「文章の手直し」の囲み（handEditStart／handEditEnd／handAsk）です。
- SN v1.9 から、読み取りの確認の画面に「児童との対応」が出ます。計画ごとに、取り込む先（いまの学級の児童／名簿の児童／新しく足す／取り込まない）を、氏名→氏名の一部（姓だけ・名だけ）→ファイル名の先頭の番号の順で自動で決めます。決めきれない行は黄色になり、選び直せます。同じ児童に2つ以上の計画が行くときは取り込めません。C4thの学級名簿を計画と一緒に入れると自動で見分け、名簿の出席番号・氏名で児童を足します（名簿にいて計画がない児童も、チェックで足せます）。計画を読み込み直したときは、手で直した欄・OKを押した欄を残し、ほかの下書きを新しい評価の文で作り直します。照合の処理は `sn/index.html` の「計画と児童の照合」の囲み（kkMatch／kkRedoPlan）です。
- SN v1.10 で、実物の計画・名簿で確かめて直しました。出席番号が学年ごとの名簿（1年の2番と4年の2番が重なる）でも別の児童として照合し、学年が混ざった学級は学年→番号の順に通し番号を振って一覧に学年を出します（学級名は入れません）。2つ以上の計画でファイル名の先頭の番号が同じときは、その番号を出席番号として使いません。教師の行動・課題の文の見分け、読点のない「〜できたが〜」の分け方、手立ての言い回しを足す条件（「できました」などで終わり、手段・条件のない文だけ）も直しました。
- SN v1.11 で、外国語（5・6年）の欄を足しました（聞く・話す／読む・書く／かかわる の9項目。既定では「使う欄」オフなので、5・6年の児童がいるときはチェックを入れます）。個別の指導計画の「外国語」「外国語活動」の行は学年で振り分けます（5・6年→外国語、3・4年→外国語活動。学年が読めないときは書いてある名前のまま）。
- SN v1.12 から、評価の文がある欄で「項目を選んで足す」（それまでの「項目を選び直す」）を押して項目を選ぶと、評価の文から作った文章の**あとに**項目の文を足します（それまでは項目だけの文章に切り替わっていました）。項目の画面の上には、その欄の個別の指導計画の内容（教科・観点・学習の程度・学習内容・支援・評価の元の文）が出ます。決まりごと：計画の文章は項目がないときと同じ（めやすの字数で外す文も同じ）。選んだ項目の文は字数に関わらずすべて入れ、長くなったら字数の知らせで伝える。つなぎの「また、」は、どちらの文章にも「また、」がないときだけ。結びの一文は、足すとめやすに近づくときだけ。項目をすべて外すと、評価の文からの文章だけに戻ります。計画を読み込み直したときは、選んだ項目はそのままで計画の文章を作り直します（手で直した欄・OKを押した欄は残す）。処理は `sn/index.html` の snMix（組み立て）・kkJoinItems（つなぎ）・kkItemsPlan（項目の画面の計画の内容）です。

## データの扱い
- 入力内容（児童名・選択・下書き）は、使っているパソコンのブラウザ内（localStorage）にだけ保存されます。サーバーには送信されません。
- 共有のパソコンでは、作業後に「所見一覧」→「くわしい設定」の「学級をすべて消す」を押してください。
- 外国語活動版・特別支援学級版も同じく、入力内容はブラウザ内だけに保存されます。共有のパソコンでは「所見一覧」→「くわしい設定」の「学級をすべて消す」を押してください。
- このリポジトリには児童の情報は含まれていません。
- 特別支援学級版の「支援の手立て」は、学校の個別の指導計画の観点にそって所見向けの言い回しに書き直したものです。指導計画の原文は含めていません。
